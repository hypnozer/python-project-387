# Contributing

Commit messages follow Conventional Commits:

```text
<type>(optional-scope): short description
```

Use `feat` for new functionality, `fix` for bug fixes, and `docs`, `test`,
`refactor`, `perf`, `build`, `ci`, or `chore` for the corresponding changes.
Append `!` after the type or add a `BREAKING CHANGE:` footer for incompatible
changes. All commits must follow this format.
